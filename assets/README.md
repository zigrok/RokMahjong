# Assets

## Generated tile art

`art/tile-atlas.png` and `art/tile-atlas.json` are generated by
`tools/RokMahjong.TileArtGen` from vector drawing code and the CJK subset font.
Do not hand-edit either file; run:

```bash
make tiles
```

The generator writes 42 traditional faces (characters, bamboo, circles, winds,
dragons, four flowers and four seasons), each with the 2.5D tile body, bevel,
side faces and soft shadow baked in. The game runtime loads the atlas as an
embedded resource, so players do not need the generator.

## Fonts

`fonts/NotoSerifCJKsc-Subset.otf` is a 14 KB subset of Noto Serif CJK SC
(SIL Open Font License 1.1) containing only the glyphs used by the tile faces.
The license is in `fonts/LICENSE.NotoSerifCJKsc.txt`. The subset is used only by
the build-time generator; it is not shipped with the game.
